Magnetic

The element leans toward the cursor as it comes near, as if pulled by a magnet, and springs back when the cursor moves away. It starts moving before the cursor reaches it, so nothing jumps as the cursor crosses its edge.

Anything

Buttons, icons, links

Any element can be magnetic. Small targets like icons can take a stronger pull, since there's less of them to move. Neighbours never collide: only the one nearest the cursor pulls, and it stops at the cursor rather than passing it. Run the cursor along the row.

Depth

Layers that move apart

Children marked with data-magnetic-depth move that many times as far as the element itself, so a card's contents seem to float above it.

Your own style

It's just three CSS variables

Every frame writes --magnetic-x, --magnetic-y and --magnetic-amount onto the element, as plain numbers. The default turns them into a translate. Write your own transform to use them some other way, in whatever unit fits.

Area

A bigger catch area

data-magnetic-area measures the pull against an ancestor instead of the element. The arrow below reacts anywhere in its panel, not just near itself.
