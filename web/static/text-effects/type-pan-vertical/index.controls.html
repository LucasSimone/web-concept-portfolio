Where the caret pins horizontally in the window once the line overflows it — closer to 1 shows more text already typed, closer to 0 shows more empty room ahead.
How quickly the window catches up to the caret. Lower = a softer, trailing pan; higher = an instant, snappy one.
On: scrolling back up erases already-typed characters, like undoing the typing. Off: typed text is kept permanently and reverse scroll just rewinds the camera across it.
