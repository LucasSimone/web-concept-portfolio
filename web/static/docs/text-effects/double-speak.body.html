Text Effect · Scroll-driven

Double Speak

Clones the element's text into a translucent "ghost" copy layered behind it. As the page scrolls, the ghost lags behind the real text with spring/ease physics, creating a smeared double-exposure trail.

View Demo Download JS

Install

<script src="double-speak.js"></script>

Self-contained — it injects its own <style> tag on first use, so no companion CSS file is required.

Usage

<div class="double-speak">Double Speak</div>
<script src="double-speak.js"></script>

Auto-initializes on DOMContentLoaded against every .double-speak element, reading its existing innerHTML. To configure options instead of using the defaults, call it yourself: 

DoubleSpeak.initAll('.double-speak', {
  offsetY: 40,
  lag: 0.2,
  opacity: 0.4,
});

Options

OptionDefaultDescription
offsetX0Max horizontal ghost displacement in px (0 disables X movement)
offsetY60Max vertical ghost displacement in px (0 disables Y movement)
lag0.15Easing factor (0.01–1) for how quickly the ghost catches up to its target position
speed1Multiplier applied to scroll delta before it drives displacement
opacity0.5Opacity of the ghost layer
blur0CSS blur (px) applied to the ghost layer
colornullExplicit ghost text color; falls back to the inherited color if null
invertedfalseIf true, the front (real) text lags instead of the ghost
rebound00–2, adds spring/bounce physics instead of plain easing when above 0
scrollSourcenullElement to listen for scroll on instead of window

Notes

Scroll-driven only — there's no continuous/time-based mode for this effect. DoubleSpeak.get(elOrSelector) and DoubleSpeak.getAll(selector) retrieve existing instances; each instance also exposes .update(options), .setText(html) (replaces both the front and ghost layers' content), .resync() (resets the internal scroll reference to the current position — useful after teleporting the scroll source, e.g. an in-page anchor jump, so the next scroll delta isn't computed against a stale position), and .destroy().
