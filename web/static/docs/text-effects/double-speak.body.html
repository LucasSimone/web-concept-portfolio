Text Effect · Scroll-driven

Double Speak

Clones the element's text into a translucent "ghost" copy layered behind it. As the page scrolls, the ghost lags behind the real text with spring/ease physics, creating a smeared double-exposure trail.

Install

<script src="double-speak.js"></script>

Self-contained — it injects its own <style> tag on first use, so no companion CSS file is required.

Quick Start

<div class="double-speak">Double Speak</div>
<script src="double-speak.js"></script>

Auto-initializes on DOMContentLoaded against every .double-speak element, reading its existing innerHTML. To configure options instead of using the defaults, call it yourself: 

DoubleSpeak.initAll('.double-speak', {
  offsetY: 40,
  lag: 0.2,
  opacity: 0.4,
});

Recipes

Subtler, softer ghost

A quieter trail for body text or anywhere the full default displacement feels too loud — smaller offset, lower opacity, and a touch of blur so it reads as a soft smear rather than a sharp duplicate. 

DoubleSpeak.initAll('.double-speak', {
  offsetY: 24,
  opacity: 0.25,
  blur: 1,
});

Horizontal-only drift

Setting offsetY to 0 disables vertical movement entirely, leaving a sideways-only ghost — a different read than the default vertical lag. 

DoubleSpeak.initAll('.double-speak', {
  offsetX: 30,
  offsetY: 0,
});

Inverted — the real text lags

Flips which layer moves: the front (real) text trails behind while the ghost stays put, instead of the default where the ghost is the one lagging. 

DoubleSpeak.initAll('.double-speak', {
  inverted: true,
});

Spring/bounce instead of plain ease

rebound above 0 swaps the plain easing for spring physics, so the ghost overshoots and settles instead of smoothly catching up. 

DoubleSpeak.initAll('.double-speak', {
  rebound: 1,
});

Drive it from a custom scroll container

By default it listens on window. Point scrollSource at any scrollable element instead to tie the effect to that container's scroll position. 

DoubleSpeak.initAll('.double-speak', {
  scrollSource: document.querySelector('.scroll-panel'),
});

Options

OptionDefaultDescription
offsetX0Max horizontal ghost displacement in px (0 disables X movement)
offsetY60Max vertical ghost displacement in px (0 disables Y movement)
lag0.15Easing factor (0.01–1) for how quickly the ghost catches up to its target position
speed1Multiplier applied to scroll delta before it drives displacement
opacity0.5Opacity of the ghost layer
blur0CSS blur (px) applied to the ghost layer
colornullExplicit ghost text color; falls back to the inherited color if null
invertedfalseIf true, the front (real) text lags instead of the ghost
rebound00–2, adds spring/bounce physics instead of plain easing when above 0
scrollSourcenullElement to listen for scroll on instead of window

Methods

MethodDescription
.update(options)Merges new options into the instance and re-applies opacity/blur/color immediately.
.setText(html)Replaces both the front and ghost layers' content.
.resync()Resets the internal scroll reference to the current position — useful after teleporting the scroll source, e.g. an in-page anchor jump, so the next scroll delta isn't computed against a stale position.
.destroy()Stops the animation loop and removes the scroll listener.
DoubleSpeak.get(elOrSelector) / DoubleSpeak.getAll(selector)Static lookups for already-initialized instances, by element/selector.

Notes

Scroll-driven only — there's no continuous/time-based mode for this effect.
