Triple Vision

An old-school red/cyan 3D-glasses anaglyph print effect. Clones the text into a red-tinted and cyan-tinted layer, blended with mix-blend-mode: multiply, that split apart in opposite directions and snap back together — like a misregistered print separation.

Install

<script src="triple-vision.js"></script>

Self-contained — it injects its own <style> tag on first use, so no companion CSS file is required.

Quick Start

<div class="triple-vision">Triple Vision</div>
<script src="triple-vision.js"></script>

Auto-initializes against every .triple-vision element, reading its existing innerHTML. Switch drive mode and configure options with: 

TripleVisionText.initAll('.triple-vision', {
  mode: 'continuous',
  continuousProfile: 'rotate',
  offsetX: 100,
  offsetY: 0,
  lag: 0.15,
  opacity: 0.6,
});

Recipes

Continuous vibrate (periodic kicks)

Text stays in place; an X-axis kick fires, settles, waits out interval, then fires again — no scroll needed. 

TripleVisionText.initAll('.triple-vision', {
  mode: 'continuous',
  continuousProfile: 'vibrate',
  offsetX: 12,
  interval: 1200,
});

Continuous rotate (constant orbit)

Both channels continuously orbit the still text at a constant rate instead of kicking and resting. 

TripleVisionText.initAll('.triple-vision', {
  mode: 'continuous',
  continuousProfile: 'rotate',
  offsetX: 8,
  speed: 1,
});

Scroll-driven with spring/bounce

Keeps the default scroll-driven split, but replaces the plain easing with spring physics via rebound, so the channels overshoot and settle instead of just catching up. 

TripleVisionText.initAll('.triple-vision', {
  mode: 'scroll',
  rebound: 1,
  offsetX: 20,
  offsetY: 40,
});

Inverted lead channel

Swaps which channel leads the split — like flipping a pair of 3D glasses. 

TripleVisionText.initAll('.triple-vision', {
  inverted: true,
});

Custom channel colors

Overrides the default red/cyan tint on each channel. 

TripleVisionText.initAll('.triple-vision', {
  redColor: '#ff0055',
  cyanColor: '#00ffcc',
  opacity: 0.6,
});

Options

OptionDefaultDescription
mode'scroll''scroll' or 'continuous' drive mode
continuousProfile'vibrate'In continuous mode: 'vibrate' (periodic X-axis kicks) or 'rotate' (both channels orbit at a constant rate)
interval3000ms between vibrate pulses (continuous + vibrate only)
offsetX0Max horizontal channel displacement in px (also orbit radius in rotate mode)
offsetY60Max vertical channel displacement in px
lag0.15Easing factor (0.01–1) for how quickly channels settle toward target
speed1Multiplier on scroll-delta input (scroll mode) or orbit rate (rotate mode)
opacity0.75Opacity of each red/cyan channel
blur0CSS blur (px) applied to each channel
redColor'#ff2b3d'Color of the red channel
cyanColor'#00c2ff'Color of the cyan channel
invertedfalseSwaps which channel leads (like flipping 3D glasses)
rebound00–2, adds spring/bounce physics when above 0
scrollSourcenullElement to listen for scroll on instead of window

Methods

MethodDescription
.update(options) Merges new options in. Switching mode or continuousProfile resets the channels to rest first.
.setText(html) Replaces the front layer and both channels' content.
.resync() Resets the internal scroll reference to the current position — useful after teleporting the scroll source (e.g. an in-page anchor jump), so the next scroll delta isn't computed against a stale position.
.destroy() Tears an instance down - stops its animation loop and removes its scroll listener.
TripleVisionText.get(elOrSelector) / TripleVisionText.getAll(selector) Static lookups for already-initialized instances, by element/selector.
