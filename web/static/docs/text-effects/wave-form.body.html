Text Effect · Continuous

Wave Form

Splits text into per-character spans that continuously drift up and down on layered sine waves — a base wave plus a faster shimmer wave — with pointer position adding directional drift and rotation.

Install

<script src="wave-form.js"></script>

Self-contained — it injects its own <style> tag on first use, so no companion CSS file is required.

Quick Start

<div class="wave-form" data-text="Wave Form">Wave Form</div>
<script src="wave-form.js"></script>

Reads the data-text attribute if present, else falls back to trimmed textContent. Auto-initializes against every .wave-form element. To configure options: 

WaveForm.initAll('.wave-form', {
  amplitude: 6,
  frequency: 0.8,
  spread: 1.1,
  drift: 0.6,
});

Recipes

Calm, ambient drift

Lower amplitude, frequency, and drift together for a slow, subtle sway instead of the energetic default. 

WaveForm.initAll('.wave-form', {
  amplitude: 8,
  frequency: 0.4,
  drift: 0.3,
});

Ripple across the word

A higher spread offsets each character's phase further from its neighbors, so the wave visibly ripples left-to-right across the word instead of every character moving in near-unison. 

WaveForm.initAll('.wave-form', {
  spread: 2.5,
});

No shimmer, just drift

Turns off the opacity oscillation, leaving only the positional movement — useful over a background where flickering opacity reads as noisy. 

WaveForm.initAll('.wave-form', {
  fade: false,
});

Fast and energetic

Bigger amplitude and drift push both the displacement and the perceived oscillation speed higher for a more frantic wave. 

WaveForm.initAll('.wave-form', {
  amplitude: 24,
  drift: 1.4,
});

Options

OptionDefaultDescription
amplitude16Peak vertical wave/shimmer displacement in px
frequency0.8Base oscillation speed multiplier
spread1.2Phase offset per character index — higher values ripple across the word instead of moving in unison
drift0.7Adds to the wave's frequency multiplier, increasing perceived speed
fadetrueWhether character opacity oscillates (shimmer fade) or stays fixed at 1

Methods

MethodDescription
.update(options)Merges new options into the running instance.
.setText(value)Re-splits into new character spans for the given text; an empty/falsy value clears the element.
.destroy()Stops the animation loop and removes the pointermove listener.
WaveForm.get(elOrSelector) / WaveForm.getAll(selector)Static lookups for already-initialized instances, by element/selector.

Notes

Continuous/time-driven only — a requestAnimationFrame loop keyed off performance.now(), with pointer position perturbing it. No scroll dependency and no mode toggle.
