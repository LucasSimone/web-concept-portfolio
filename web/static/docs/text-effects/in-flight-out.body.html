Text Effect · Scroll-driven

In Flight Out

Splits text into per-character spans that fly in from scattered off-screen paths, assemble and hold while the element crosses the viewport, then fly apart and off-screen again — driven exactly by scroll position, so it's fully reversible.

Install

<script src="in-flight-out.js"></script>

Self-contained — it injects its own <style> tag on first use, so no companion CSS file is required.

Quick Start

<div class="in-flight-out" data-text="In Flight Out">In Flight Out</div>
<script src="in-flight-out.js"></script>

Reads data-text or trimmed textContent. Auto-initializes against every .in-flight-out element. To configure options: 

InFlightOut.initAll('.in-flight-out', {
  scatter: 0.45,
  maxDistance: 60,
  rotation: 0.4,
  maxAngle: 40,
});

Recipes

Scatter from every edge, not just top/bottom

The default 'linear' path enters from below and exits above, like scrolling credits. 'random' gives each letter its own independent off-screen edge — top, right, bottom, or left — so the assembly looks scattered instead of a single crawl direction. 

InFlightOut.initAll('.in-flight-out', {
  path: 'random',
});

Subtle, short-distance entrance

Pull the letters in from just off-frame instead of flinging them across the whole viewport — a calmer assemble for body copy rather than a big display headline. 

InFlightOut.initAll('.in-flight-out', {
  scatter: 0.3,
  maxDistance: 50,
});

Heavy tumble

Push rotation toward 1 so nearly every letter spins as it flies, and raise maxAngle for a full tumble instead of a slight tilt. 

InFlightOut.initAll('.in-flight-out', {
  rotation: 0.9,
  maxAngle: 120,
});

Longer hold, snappier entry/exit

entryPercent/hangPercent/exitPercent split the scroll range into three phases. Shrinking the entry and exit shares (and giving the difference to hang) makes the letters snap together quickly, sit fully assembled for most of the scroll, then snap apart just as fast. 

InFlightOut.initAll('.in-flight-out', {
  entryPercent: 20,
  hangPercent: 60,
  exitPercent: 20,
});

Options

OptionDefaultDescription
scatter1Multiplier scaling how far entry/exit points are from center
maxDistance140Cap on flight distance, as % of viewport diagonal
rotation0.40–1 chance-and-intensity dial for how many/how much letters rotate
maxAngle60Max rotation angle in degrees when rotation is fully active
entryPercent48Share of scroll progress spent on the entry animation
hangPercent10Share of scroll progress the text holds fully assembled
exitPercent42Share of scroll progress spent on the exit animation
path'linear''linear' (enter below / exit above, like credits) or 'random' (each letter enters/exits from a random viewport edge)

Methods

MethodDescription
.update(options)Merges new options in.
.reshuffle()Re-rolls random entry/exit points and rotation without rebuilding the DOM or touching options.
.setText(value)Replaces the text (rebuilds the per-character spans).
.destroy()Stops the instance's animation loop and removes its scroll/resize listeners.
InFlightOut.get(elOrSelector) / InFlightOut.getAll(selector)Static lookups for already-initialized instances, by element/selector.

Notes

Scroll-driven only — no continuous mode.
