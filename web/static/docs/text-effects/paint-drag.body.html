Text Effect · Scroll-driven

Paint Drag

The real text scrolls normally with the page. A single shared canvas fixed to the viewport stamps the text at its current screen position every frame, leaving a fading paint-like smear behind it — a brush dragged across the screen rather than a trail that travels with the text.

Install

<script src="paint-drag.js"></script>

Self-contained — it injects its own <style> tag on first use, so no companion CSS file is required.

Quick Start

<div class="paint-drag">Paint Drag</div>
<script src="paint-drag.js"></script>

Reads data-text if present, else trimmed textContent. Auto-initializes against every .paint-drag element — note all instances on a page share one fixed full-viewport canvas. To configure options: 

PaintDrag.initAll('.paint-drag', {
  smearLength: 0,
  spread: 0,
  blur: 2,
  fadeTime: 0.1,
  density: 0,
});

Recipes

Long, bold smear

Stretches the stroke further beyond the text's real movement and softens each stamp, for a heavier, more exaggerated drag. 

PaintDrag.initAll('.paint-drag', {
  smearLength: 260,
  blur: 12,
});

Tight, precise trail

Turns off the perpendicular jitter and the slant-along-drag skew, so fast movement leaves a clean, straight stroke instead of a scattered one. 

PaintDrag.initAll('.paint-drag', {
  spread: 0,
  skew: false,
});

Quick-fading, subtle trail

A lighter touch — fewer interpolated stamps per frame and a fast fade, so the mark reads more like a faint flicker than a lingering smear. 

PaintDrag.initAll('.paint-drag', {
  density: 4,
  fadeTime: 0.25,
});

Custom trail color

Overrides the default (the element's own computed text color) with an explicit color, independent of whatever color the live text itself is styled with. 

PaintDrag.initAll('.paint-drag', {
  color: '#ff3366',
});

Stack beneath fixed page chrome

The shared trail canvas defaults to sitting above virtually everything. Lower zIndex below a fixed/sticky nav's own z-index (this site's nav uses 20) so the nav stays on top instead of getting painted over. 

PaintDrag.initAll('.paint-drag', {
  zIndex: 15,
});

Options

OptionDefaultDescription
smearLength140How far the stroke is stretched beyond real movement, in px, at full speed
spread18Perpendicular random jitter/scatter of each brush stamp, in px
fadeTime0.6Seconds for a stamp/trail to fully fade after motion stops
density10Max interpolated stamps drawn per frame at full speed
blur6Canvas shadow blur per stamp (bristle softness)
skewtrueWhether stamps slant/rotate along the drag direction
colornullExplicit trail color; defaults to the element's computed text color
zIndex2147483646Stacking height of the shared trail canvas (the live text sits one above it); lower this below any fixed/sticky page chrome that should stay on top

Methods

MethodDescription
.update(options)Merges new options in.
.setText(value)Changes the text being stamped (updates both data-text and the element's visible content).
.clear()Wipes the shared canvas immediately instead of waiting for fadeTime to elapse.
.destroy()Stops the instance's animation loop (the shared canvas itself is only removed when the page unloads).
PaintDrag.get(elOrSelector) / PaintDrag.getAll(selector)Static lookups for already-initialized instances, by element/selector.

Notes

Implemented as a continuous requestAnimationFrame loop that samples getBoundingClientRect() each frame rather than a scroll listener, but reads as scroll-driven since velocity comes from the element's on-screen position changing as the page scrolls. The injected canvas overlay uses a very high z-index to sit above host-page content.
