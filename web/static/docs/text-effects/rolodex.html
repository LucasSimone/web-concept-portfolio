Text Effect · Scroll + Continuous

Rolodex

Splits a sentence into words and shows them one at a time on a fixed-size 3D card that flips to the next word — either a two-flap "split-flap" display or a single-card front/back flip — as the user scrolls, or on a timed loop in continuous mode.

View Demo Download JS

Install

<script src="rolodex.js"></script>

Self-contained — it injects its own <style> tag covering the 3D card/flap/panel structure on first use, so no companion CSS file is required. Note the injected CSS hardcodes a white background on card faces.

Usage

<div class="rolodex" data-text="Rolodex flips through words one by one">
  Rolodex flips through words one by one
</div>
<script src="rolodex.js"></script>

Reads data-text or trimmed textContent, splitting on whitespace into words. Auto-initializes against every .rolodex element — card size is measured via an offscreen canvas based on the widest word and computed font. To switch drive mode and configure options: 

Rolodex.initAll('.rolodex', {
  mode: 'split-flap',
  driveMode: 'continuous',
  flipWidth: 55,
  perspective: 900,
  shading: 0.05,
});

Options

OptionDefaultDescription
mode'split-flap'Visual style: 'split-flap' (two-flap card) or 'single-card' (simple front/back flip)
driveMode'scroll''scroll' (scroll position mapped across word segments) or 'continuous' (self-animating hold/flip/rewind loop)
flipWidth55% of each word's segment spent mid-flip (the rest holds on a settled word)
perspective900CSS 3D perspective in px for the flip
shading0.550–1, how much a flap darkens as it turns edge-on
interval1400ms held on each word before flipping (continuous mode)
flipDuration450ms spent mid-flip between words (continuous mode)
rollbackSpeed900ms to rewind from the last word back to the first (continuous mode)

Notes

.remeasure() recomputes card size after a font change; .setText(value) replaces the sentence being flipped through.
