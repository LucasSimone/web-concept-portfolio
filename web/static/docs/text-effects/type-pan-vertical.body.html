Text Effect · Scroll-driven

Type Pan Vertical

A fixed-width clipped "window" types out a single line of text character by character as the user scrolls down the page. Once the typed line grows wider than the window, the window pans horizontally to keep the caret in view instead of wrapping. Scroll position drives the typing exactly, so it's reversible/scrubbable.

Install

<script src="type-pan-vertical.js"></script>

Self-contained — it injects its own <style> tag (including the blink keyframes) on first use, so no companion CSS file is required.

Usage

<div class="type-pan-vertical" data-text="Type Pan scrolls the carriage sideways as the line keeps growing.">
  Type Pan scrolls the carriage sideways as the line keeps growing.
</div>
<script src="type-pan-vertical.js"></script>

Reads data-text or trimmed textContent. Auto-initializes against every .type-pan-vertical element. To configure options: 

TypePanVertical.initAll('.type-pan-vertical', {
  panPosition: 0.6,
  lag: 0.18,
});

Options

OptionDefaultDescription
panPosition0.62Fraction of window width the caret pins to once text overflows
lag0.18Smoothing (0–1) applied to the pan movement; higher is snappier
eraseOnReversetrueErase typed characters when scrolling back up; false keeps text and only rewinds the camera
cursorBlinktrueWhether the caret blinks

Notes

Scroll-driven only — no continuous mode in this variant (unlike its horizontal sibling, Type Pan Horizontal).
