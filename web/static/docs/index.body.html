Web Lab Docs

Every effect below is a single self-contained JavaScript file — no build step, no dependencies. It injects its own CSS, auto-initializes on DOMContentLoaded against a default class selector, and exposes an initAll(selector, options) helper for configuring it yourself. Drop the file on a page, add the class to an element, and it runs.

Pick an effect from the sidebar for its options, usage snippet, and a link back to its live demo. Each demo page also has a "Download JS" button in the top-right of the nav that grabs that exact file.

Multiple Instances

Running two of the same effect with different settings on one page is simple — each instance merges its own options in its constructor ({...DEFAULTS, ...options}) and keeps them on this.options, so there's no shared/global config to collide. Either call initAll against two different selectors, or construct instances directly: 

// two different selectors, each with its own options
Rolodex.initAll('#header-rolodex', { driveMode: 'continuous', interval: 800 });
Rolodex.initAll('#footer-rolodex', { driveMode: 'scroll', flipWidth: 30 });

// or instantiate directly
new Rolodex(document.getElementById('a'), { mode: 'single-card' });
new Rolodex(document.getElementById('b'), { mode: 'split-flap' });

The one exception is Paint Drag: every instance on a page draws onto one shared, viewport-fixed canvas for performance. Each instance still resets the canvas state (blur, color) from its own options right before drawing, so differing settings per instance render correctly — but calling .destroy() on one instance clears the entire shared canvas, wiping every instance's trail, not just its own.

Text Effects

Double Speak A translucent ghost copy of the text lags behind the real text as you scroll, like a double exposure. Wave Form Characters drift on layered sine waves, continuously, with pointer position steering the motion. Paint Drag Text scrolling past leaves a fading brush-like smear stamped onto a fixed canvas overlay. In Flight Out Letters fly in from scattered points, assemble while in view, then scatter apart again on scroll. Triple Vision A red/cyan anaglyph print misregistration effect, split apart by scroll or a continuous vibrate/rotate loop. Type Pan A line types itself out and pans horizontally once it overflows, by page scroll, a timed loop, or wheel input while hovering. Rolodex Words flip through one at a time on a 3D split-flap or single-card display, by scroll or on a timed loop.

Background

Circuit Board A canvas PCB background where traces light up and travel along a random grid, fading in and out forever. Gravity Well A wireframe grid that bends toward the cursor like a sheet being pulled, easing back to flat as it leaves. Vacuum Text, images, and borders shed colored dust toward the cursor when it gets close, sampled from their own actual colors.

Page Transitions

A different kind of effect: instead of animating an element, it installs into <head> and animates the moment between pages — an exit motion on the page you're leaving, picked up seamlessly as the next page loads.

Shutter A black panel rises from the bottom edge to cover the screen on exit, then recedes to reveal the next page on load.
