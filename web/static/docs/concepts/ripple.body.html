Ripple

Press an element and a ripple spreads out from the point you pressed, reaching its farthest corner. Hold it and the ripple stays; let go and it fades. It's drawn beneath the element's content but above its background, so text on the element stays exactly as legible as it was. It comes as a fill, a ring, a soft glow or concentric rings, or a shape of your own, and takes the element's text color unless you give it one.

Install

<script src="ripple.js"></script>

Injects its own <style> tag for the layer and the ripples, so no companion CSS file is needed.

Quick Start

<button class="ripple-el">Save</button>
<script src="ripple.js"></script>

Every .ripple-el on the page is set up on load. Data attributes change that per element: 

<div class="ripple-el" data-ripple-shape="ring">...</div>
<button class="ripple-el" data-ripple-color="#ffe14d">Go</button>
<button class="ripple-el icon"
        data-ripple-contained="false"
        data-ripple-origin="center">★</button>

The attributes are data-ripple-shape, -color, -opacity, -duration, -origin, -contained and -size. They win over options passed to initAll. To set options for a group of elements in code: 

Ripple.initAll('.card', { shape: 'soft', duration: 800 });

Run that as a plain script straight after ripple.js, before the page finishes loading: once auto-init has claimed an element, initAll skips it. To change one that's already set up, use Ripple.get(el).update(options).

Pressing

A ripple starts on pointerdown, so it shows the moment the element is pressed, not when the click lands. It spreads over duration ms and holds at full size for as long as the press does. Letting go, the pointer leaving the element, or the press being cancelled (a touch turning into a scroll) fades it over fadeDuration ms. A quick click lets the ripple show for at least a third of duration first, and it keeps spreading as it fades.

A click from the keyboard (Enter or Space on a button) has no pointer position, so it ripples from the center and fades straight away. Disabled elements, and elements with aria-disabled="true", don't ripple. Several fingers on a touchscreen each get their own ripple.

By default a ripple is clipped to the element's outline, rounded corners included, and grows until it reaches the corner farthest from where it started. contained: false lets it spread past the edge, and size sets its full radius in px instead. Together with origin: 'center' they make a ring around an icon button.

Firing From Code

The press wiring is a thin layer over one function you can call yourself, on any element, set up or not. It takes the same options as an element does. 

// From a point, in window coordinates (clientX / clientY).
const ripple = Ripple.at(el, event.clientX, event.clientY, { shape: 'ring' });

// It stays until you let it go.
ripple.release();

// From the center, released at once: a whole tap.
Ripple.at(el).release();

Recipes

Ripple while hovered

Since a ripple holds until it's released, a hover can drive one: start it where the pointer comes in, let it go when it leaves. 

let ripple = null;
card.addEventListener('pointerenter', (e) => {
  ripple = Ripple.at(card, e.clientX, e.clientY, { duration: 700 });
});
card.addEventListener('pointerleave', () => ripple && ripple.release());

Confirm a save

Fire it when the work is done rather than on the click, so it means the save went through. 

await save();
Ripple.at(button, null, null, { shape: 'rings', origin: 'center' }).release();

A soft glow on dark cards

Ripple.initAll('.dark-card', { shape: 'soft', color: '#fff', opacity: 0.25 });

Shapes

Ripple.SHAPES lists the built-in names:

  • 'fill' (the default): a solid disc, at 0.22 opacity.
  • 'ring': an outline, at 0.6. Best with a short hold, or with contained: false around a small element.
  • 'soft': a disc that fades out toward its edge, at 0.4.
  • 'rings': three concentric rings, at 0.45.

Write your own

A shape is a function that styles one square element, the ripple at its full size. It's called as draw(el, { size, color }), once per ripple. The color is already set as the element's CSS color, so paint with currentColor, and the element is already a circle (border-radius: 50%) unless you say otherwise. The spread from nothing and the fade are done for you, the same for every shape, by animating transform and opacity, so leave those two alone. 

// A ring that glows on both sides.
Ripple.addShape('halo', (el) => {
  el.style.border = '2px solid currentColor';
  el.style.boxShadow = '0 0 16px currentColor, inset 0 0 16px currentColor';
}, { opacity: 0.5 });

A shape added by name works everywhere a built-in does, data attributes included (data-ripple-shape="halo"), and can be added after the page is set up: shapes are looked up when a ripple starts. shape also takes a function directly, with an opacity of 0.3. A function that throws is swapped for a fill on that ripple, with the error in the console.

Notes

The first ripple on an element appends one <span class="ripple-layer"> to it, and each ripple is a <span class="ripple"> inside that, animated with the Web Animations API and removed once it has faded. There's no animation loop. The layer sits at z-index: -1 in a stacking context of the element's own, which is what puts it over the element's background and under its content. To make that context, an element whose position is static gets position: relative, and its isolation is set to isolate, both inline. If your CSS matches an element's :last-child, the layer is now its last child.

Respects prefers-reduced-motion without switching off: a ripple is feedback that a press landed, so under reduced motion it fades in at full size instead of spreading, then fades out as usual. The demo page edits shape, color, opacity (as a multiplier on each element's own), duration and fadeDuration on every element. Its Shape and Color controls start on each element's own, so the shape pads and the colored buttons show their own settings until you pick something else.
