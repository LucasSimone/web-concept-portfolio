Confetti

Paper confetti, fired by a click. It comes in three modes: out of the clicked element's edges, out of the exact point the cursor clicked, or across the whole window. Element and cursor confetti go in whatever direction you give them, by name or in degrees, or every direction at once. Screen confetti shoots up from the bottom edge, drops from the top, or fires in from the two bottom corners. Each piece pops out fast, air drag slows it almost at once, and it flutters down swaying, spinning and tumbling end over end, so its darker back face flashes as it turns.

Install

<script src="confetti.js"></script>

Injects its own <style> tag for the one canvas it draws on, so no companion CSS file is needed. Nothing is added to the page until the first confetti is fired.

Quick Start

<button class="confetti-el">Celebrate</button>
<script src="confetti.js"></script>

Every .confetti-el on the page is set up on load, and a click on one fires confetti up out of its top edge. Data attributes change that per element, so one blanket auto-init still covers buttons that each do something different: 

<button class="confetti-el" data-confetti-direction="all">All around</button>
<div class="confetti-el" data-confetti-mode="mouse">Click anywhere</div>
<button class="confetti-el" data-confetti-mode="screen" data-confetti-from="top">
  Make it rain
</button>

The attributes are data-confetti-mode, -direction, -from, -count, -spread and -reach. They win over options passed to initAll. To set options for a group of elements in code: 

Confetti.initAll('.save-button', {
  colors: ['#2a9d8f', '#e9a800'],
  count: 80,
});

Run that as a plain script straight after confetti.js, before the page finishes loading: once auto-init has claimed an element, initAll skips it. To change one that's already set up, use Confetti.get(el).update(options). If your elements don't carry the confetti-el class, auto-init never touches them and you can call initAll any time.

Modes

  • 'element' (the default): out of the clicked element's edges, in direction.
  • 'mouse': out of the point that was clicked, in direction. A click from the keyboard (Enter or Space on a button) has no pointer position, so it fires from the middle of the element.
  • 'screen': across the whole window, from 'bottom' (the whole bottom edge shoots up), 'top' (it drops in from above and rains down) or 'sides' (two cannons in the bottom corners fire up and inward). The element is only the trigger.

Each mode has its own defaults for count, spread, reach and duration, since a shower across the window wants several times the pieces of a button pop. Leaving one of them out (or setting it to null) uses the mode's own value. See Options.

Direction

direction applies to element and mouse confetti. It takes any of:

  • A name: 'up', 'down', 'left', 'right', 'up-left', 'up-right', 'down-left', 'down-right'.
  • An angle in degrees, compass style, the same as a CSS gradient's angle: 0 is straight up, 90 right, 180 down, 270 left. Numeric strings work too, so data-confetti-direction="120" is fine.
  • 'all': every way at once.

spread fans pieces out across a cone that many degrees wide, centered on the direction. 0 fires one straight line and 360 fires every way.

With a direction, element confetti leaves from every edge that faces that way at all, each in proportion to how squarely it faces it. 'up' is the top edge only, and 'up-right' is the top and right edges together, with every piece flying the one way. With 'all', pieces leave from anywhere around the outline, each straight out from its own edge (give or take spread), so a wide button throws most of its confetti up and down. Mouse confetti with 'all' goes out evenly in a full circle.

Firing From Code

The click wiring is a thin layer over three functions you can call yourself, with no element set up at all. They take the same options as an element does. 

// Out of an element's edges (an element or a selector).
Confetti.fromElement('#save', { direction: 'all' });

// Out of a point, in window coordinates (clientX / clientY).
Confetti.burst(event.clientX, event.clientY, { direction: 135 });

// Across the whole window.
Confetti.screen({ from: 'top' });

Recipes

Celebrate a form going through

Fire it when the work is actually done, not on the click, so a failed submit doesn't celebrate. 

form.addEventListener('submit', async (event) => {
  event.preventDefault();
  await send(new FormData(form));
  Confetti.screen({ from: 'sides' });
});

A button that bursts on all sides

<button class="confetti-el"
        data-confetti-direction="all"
        data-confetti-count="90">Like</button>

Out of the cursor, aimed down-right

Confetti.initAll('.board', {
  mode: 'mouse',
  direction: 135,
  spread: 30,
});

A gentle drift

Low gravity keeps pieces in the air longer, since they fall at about a third of gravity px per second once drag has caught them. Reach stays about the same: launch speed is worked out from it. 

Confetti.screen({
  from: 'top',
  gravity: 200,
  count: 120,
  shapes: ['circle'],
  colors: ['#a7c4f2', '#c9b3ec'],
});

Shapes

shapes is a list, and each piece picks one entry from it at random, so repeating an entry makes it more common. Confetti.SHAPES lists the built-in names: 'square', 'strip' (a long thin scrap), 'circle', 'triangle' and 'star'.

Write your own

An entry can also be a function. It's called as draw(ctx, size) for every piece on every frame, and should fill a shape about size px across, centered on (0, 0). The fill color is already set, and the piece's position, spin and tumble are already applied to the context, so draw it flat. Keep it cheap: a few hundred pieces call it 60 times a second. A function that throws is swapped for a square on that piece, with the error in the console, rather than stopping the animation. 

function heart(ctx, size) {
  const s = size / 2;
  ctx.beginPath();
  ctx.moveTo(0, s * 0.9);
  ctx.bezierCurveTo(-s * 1.2, 0, -s * 0.9, -s * 1.1, 0, -s * 0.45);
  ctx.bezierCurveTo(s * 0.9, -s * 1.1, s * 1.2, 0, 0, s * 0.9);
  ctx.fill();
}

Confetti.initAll('.like-button', {
  shapes: [heart, heart, 'circle'],
  colors: ['#e63946', '#ff7a8a'],
});

Emoji work the same way, as text: 

function party(ctx, size) {
  ctx.font = `${size * 1.6}px sans-serif`;
  ctx.textAlign = 'center';
  ctx.textBaseline = 'middle';
  ctx.fillText('🎉', 0, 0);
}

Notes

All the confetti on a page, from every element and every call, draws into one canvas fixed over the window, added the first time anything fires. It ignores the pointer, so it never gets in the way of a click, and its animation loop stops whenever nothing is in the air, so idle confetti buttons cost nothing. It sits at z-index: 2147483000, above almost anything; override .confetti-canvas to tuck it under a modal of your own. Because the canvas is fixed to the window, confetti stays where it is on screen if the page scrolls under it.

Respects prefers-reduced-motion: under it every way of firing does nothing at all, since there's no still version of confetti that would mean anything. Clicks still reach the element as normal. The demo page edits count (as a multiplier on each mode's own), spread, reach, gravity, size, shapes and colors, and leaves spread and reach alone on the screen buttons.
