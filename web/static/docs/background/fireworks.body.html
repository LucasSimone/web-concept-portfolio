Fireworks

A canvas of fireworks. Rockets go up from the bottom edge at random places and times, wobbling slightly and dropping a faint trail of sparks, and slow to a stop at the top of their climb, where they burst. A burst throws particles outward that slow with drag, fall under gravity, shrink and fade, leaving short trails. About one particle in eight twinkles as it fades, and about one in twelve crackles into a pop of tiny sparks when it goes out. The sky is white by default and takes any color: over a dark one the bursts are drawn as light instead, so overlapping bursts glow brighter where they cross and the element's text turns white. Clicking the element sends a rocket up to burst at the cursor. Purely decorative otherwise — it sits behind the element's content and never touches real page elements.

Install

<script src="fireworks.js"></script>

Injects its own <style> tag positioning the canvas behind the element's content, so no companion CSS file is required to render it — but the host element needs its own height/content, since the injected CSS doesn't size it.

Quick Start

<section class="bg-fireworks" aria-label="Fireworks background">
  <span class="label">Light up the sky</span>
</section>
<script src="fireworks.js"></script>

No data attribute needed — just apply the class to a container with a size of its own. A ResizeObserver on the host element keeps the canvas sized to fit, moving everything in flight proportionally rather than restarting the show. Auto-initializes against every .bg-fireworks element. To configure options: 

Fireworks.initAll('.bg-fireworks', {
  launchRate: 2,
  burstRadius: 160,
});

Run that as a plain script straight after fireworks.js, before the page finishes loading: once auto-init has claimed an element, initAll skips it and returns nothing for it. To change one that's already running, use Fireworks.get(el).update(options).

Recipes

Night sky

Any dark background switches to drawing with light: colors add up where bursts overlap, the brightest particles run toward white rather than black, rockets are a warm glow instead of a dark streak, and the element gets the bg-fireworks--dark class, which turns its text white. Pale, bright colors suit it; the deeper defaults are picked for white. 

Fireworks.initAll('.bg-fireworks', {
  background: '#070a1a',
  colors: ['#ff4d5e', '#ffa53d', '#ffe36e', '#6ef0a0', '#62a8ff', '#c77dff'],
});

Finale

Four rockets a second, bigger bursts, every pattern. Everything on element has its own ceiling of 2,500 particles, so pushing the rate higher thins bursts out rather than slowing the page down. 

Fireworks.initAll('.bg-fireworks', {
  launchRate: 4,
  burstSize: 120,
  burstRadius: 150,
  trailLength: 0.25,
});

Golden willow

Willow bursts only, in a gold range. Each willow particle drops embers as it goes, which hang and fade on their own, so the trails are long whatever trailLength is. 

Fireworks.initAll('.bg-fireworks', {
  patterns: ['willow'],
  colors: ['#ffd27a', '#e8a33d'],
  blend: true,
  launchRate: 0.6,
  gravity: 60,
});

A range of colors

With blend on, colors is read as a gradient through the colors in the order given, instead of a list to pick from. Each burst lands somewhere along it. With blend off or on, about a quarter of bursts are two-tone whenever there's more than one color to pick from: two colors well apart, split down the middle. 

Fireworks.initAll('.bg-fireworks', {
  colors: ['#9ad0ff', '#c9b6ff', '#ffd6e8'],
  blend: true,
});

Over an existing backdrop

Set background to 'transparent' (or null) and the canvas has no sky of its own, so fireworks go off over whatever the host element shows: a photo of a skyline, a gradient. The injected styles give the host a white background and are added at the end of <head>, so override it with a more specific selector, such as .hero.bg-fireworks. Whether to draw as light or as paint is decided from the host's background color when the option is set, so a host that changes its background later should call update({ background: 'transparent' }) again. The host's text color is left to its own styles. 

Fireworks.initAll('.bg-fireworks', {
  background: 'transparent',
});

Celebrate on demand

launchRate: 0 keeps the sky empty until you call launch(), say when a form goes through. 

// Straight after fireworks.js, before auto-init claims the element.
const [show] = Fireworks.initAll('.bg-fireworks', { launchRate: 0 });
form.addEventListener('submit', () => {
  show.launch(200, 120);
  show.launch(420, 90);
});

Burst Patterns

patterns is a list, and each rocket picks one entry from it at random, so repeating an entry makes it more common. Fireworks.PATTERNS lists the built-in names:

  • 'peony' — an even ball, the classic burst.
  • 'ring' — a single ring, tilted at a random angle so it's usually seen as an ellipse.
  • 'willow' — slower, longer-lived particles that droop and leave a trail of embers.
  • 'crossette' — a few particles that each split into four a third of the way through their life.
  • 'palm' — 5 to 8 thick arms that travel far and droop heavily.

Write your own

An entry can also be a function. It's given the particle count (burstSize) and returns one starting velocity per particle, as [x, y], where a length of 1 is full burst speed: fast enough to coast burstRadius px before drag stops it, with gravity off. Positive y is down. It can return more or fewer particles than it was asked for. Entries that aren't a pair of finite numbers are skipped, and a function that throws bursts as nothing (with the error in the console) rather than stopping the show. 

// A heart. The classic parametric curve, scaled to about 1 across.
function heart(count) {
  const out = [];
  for (let i = 0; i < count; i++) {
    const t = (i / count) * Math.PI * 2;
    const x = 16 * Math.sin(t) ** 3;
    const y = -(13 * Math.cos(t) - 5 * Math.cos(2 * t) - 2 * Math.cos(3 * t) - Math.cos(4 * t));
    out.push([x / 17, y / 17]);
  }
  return out;
}

Fireworks.initAll('.bg-fireworks', {
  patterns: [heart, 'peony'],
  colors: ['#ff4d5e', '#ff8fab'],
});

For more control, pass an object instead: velocities is the same function, and any of the other fields scale that pattern's particles against the defaults. 

{
  velocities: heart,
  life: 1.5,      // × how long particles last (1.3–1.9s by default)
  drag: 0.8,      // × how quickly they slow down
  gravity: 0.5,   // × the gravity option
  size: 1.2,      // × particleSize
  embers: false,  // drop willow-style embers along the way
  split: 0,       // split into this many, a third of the way through life
}

Options

OptionDefaultDescription
launchRate1Average rockets per second, at random intervals. 0 stops automatic launches; clicks and launch() still work
burstSize90Particle count handed to each burst's pattern. Crossettes use a sixth of it (at least 6) before splitting each into four; palms about half. Each element caps its own particles at 2,500
burstRadius130How far, in px, a peony's fastest particles coast with gravity off. Automatic rockets also burst at least 0.6× this (or 10% of the height) below the top edge, and never below halfway down
gravity80Downward pull on burst particles, in px/sec². Willows feel 70% of it, palms 130%. Rockets aren't affected
trailLength0.3Seconds for the glow a particle leaves behind to fade to about 5%. Willow embers last up to a second regardless
particleSize2Starting thickness of a peony or ring particle, in px, ±20% each. Shrinks to 40% by the time it fades. Palms draw 1.6× as thick, crossettes 1.3×, willows 0.8×
background'#ffffff'The sky color behind the canvas, any CSS color. A dark one draws the bursts as additive light and adds the bg-fireworks--dark class (white text) to the element. A see-through color is judged as it looks over the host's background. 'transparent' or null leaves the host's own background showing, and picks light or dark from that; so does any other CSS background (a gradient, an image), which is applied but can't be measured
colorssix saturated hexesArray of CSS colors (hex, rgb(), named, anything the canvas accepts; transparency is ignored). Each burst picks one (or a point between them, with blend), and each particle is that color or a version 20% or 40% of the way to black (on a light sky) or white (on a dark one)
blendfalseWhen true, colors is a gradient through its colors in order, spaced evenly, and each burst lands anywhere along it. When false, each burst is exactly one of the listed colors
patterns['peony', 'peony', 'ring', 'willow', 'crossette', 'palm']Array of built-in pattern names, velocity functions or pattern objects; each rocket picks one. See Burst Patterns
clickToLaunchtrueWhether a click on the element sends a rocket up to burst at the cursor. Clicks on links, buttons and form fields inside the element are left alone. Can be switched with update() at any time

Methods

MethodDescription
.launch(x, y)Sends a rocket up from the bottom edge to burst at (x, y), in px from the element's top-left corner. Does nothing under reduced motion.
.update(options)Merges new options in. A new launchRate takes effect at once rather than after the wait already scheduled; new colors, blend and patterns apply from the next burst on, leaving bursts already in the air as they were; anything else applies on the next frame.
.destroy()Stops the animation loop, disconnects the resize and visibility observers, removes the click listener and the canvas.
Fireworks.get(elOrSelector) / Fireworks.getAll(selector)Static lookups for already-initialized instances, by element/selector.
Fireworks.PATTERNSThe names of the built-in patterns.

Notes

Trails come from never fully clearing the canvas: each frame erases part of what's there and draws the new positions on top, with additive blending on a dark sky. The erasing happens in steps of at least 12% rather than every frame, so trails can't get stuck as a faint ghost on a fast screen, and the canvas is wiped clean whenever the sky goes empty. The loop pauses when the element is scrolled well out of view. Respects prefers-reduced-motion by skipping the animation loop entirely and drawing one still frame of three bursts caught mid-spread, so the sky is still lit but doesn't move, and clicks do nothing. The demo page edits colors, blend, background and clickToLaunch directly, up to six colors; patterns only changes with its Profile dropdown, so reach for that option in code for your own patterns.
