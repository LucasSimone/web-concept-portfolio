Circuit Board

A canvas-based PCB-style background: traces (random-walk grid paths) light up as a small dot travels along each one, leaving a fading tail. Once a trace finishes it fades out entirely and a new one spawns elsewhere, so the board is in perpetual, staggered motion. Applies to any container element, not just full-page backgrounds.

Install

<script src="circuit-board.js"></script>

Injects its own <style> tag positioning the canvas behind the element's content, so no companion CSS file is required to render it — but the host element needs its own height/content, since the injected CSS doesn't size it.

Quick Start

<section class="bg-circuit-board" aria-label="Circuit board background">
  <span class="label">Applied to a full section</span>
</section>
<script src="circuit-board.js"></script>

No text/data attribute needed — just apply the class to a container with a size of its own. A ResizeObserver on the host element rebuilds the grid/canvas to fit. Auto-initializes against every .bg-circuit-board element. To configure options: 

CircuitBoard.initAll('.bg-circuit-board', {
  maxTraces: 30,
  cell: 20,
  speed: 30,
});

Recipes

Busier board

More traces alive at once, and lets them cross/share points instead of each staking out exclusive grid space — a denser, more tangled board. 

CircuitBoard.initAll('.bg-circuit-board', {
  maxTraces: 160,
  allowOverlap: true,
});

Slower, calmer board

Dots crawl instead of dart, and a finished trace lingers longer before it fades out and a new one spawns — a quieter background that doesn't compete for attention. 

CircuitBoard.initAll('.bg-circuit-board', {
  speed: 8,
  fadeDuration: 1.5,
});

Dark theme

Flips the canvas to a dark fill with light traces/pulses — colors are plain RGB triplets, not full rgb()/hex strings, for traceColor/pulseColor specifically. 

CircuitBoard.initAll('.bg-circuit-board', {
  background: '#0a0a0a',
  traceColor: '255, 255, 255',
  pulseColor: '80, 220, 255',
});

Coarser grid, fewer traces

Wider grid spacing means longer, more spaced-out trace runs. Pair it with a lower maxTraces so a coarse grid doesn't just pack in more overlap-free traces to compensate. 

CircuitBoard.initAll('.bg-circuit-board', {
  cell: 60,
  maxTraces: 20,
});

Options

OptionDefaultDescription
cell34Grid spacing in px between points traces can bend at
maxTraces80Max number of traces lit/moving at once
maxLength30Longest a trace can randomly grow, in grid steps
speed20Travel speed of each trace's dot, in px/sec
fadeDuration0.5Seconds for a finished trace to fade out (and for fade-in)
allowOverlapfalseIf true, new traces can cross/share points with existing ones
background'#ffffff'Canvas fill color drawn behind traces each frame
traceColor'0, 0, 0'RGB triplet (no rgb() wrapper) for trace line/pad color
pulseColor'0, 0, 0'RGB triplet for the traveling dot/spark color

Methods

MethodDescription
.update(options) Applies new option values. Changing cell or allowOverlap rebuilds the grid and starts a fresh pool of traces (old coordinates/occupancy no longer apply); changing maxTraces alone just grows or shrinks the live pool.
.randomize() Instantly retires every live trace and spawns a fresh pool, without changing any settings.
.destroy() Stops the animation loop, disconnects the resize observer, and removes the canvas.
CircuitBoard.get(elOrSelector) / CircuitBoard.getAll(selector) Static lookups for already-initialized instances, by element/selector.

Notes

Respects prefers-reduced-motion by freezing all lights at 50% progress and rendering a single static frame instead of animating.
