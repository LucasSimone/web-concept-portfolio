Gears

A canvas of line-drawn gears laid out in trains whose teeth really mesh. Every gear has the same size teeth, sits exactly its pitch distance from the gear it meshes with, and is turned so its teeth land in that gear's gaps. Turning one gear turns the rest of its train at the right ratio, each in the opposite direction to its neighbor: a gear half the size turns twice as fast. Some trains have a motor, marked by a filled axle, and turn on their own. Pressing on a gear grabs it, and letting go mid-turn flicks it. Moving the mouse across a gear pushes it round. A flicked train coasts back to its motor's speed, or to a stop. It sits behind the element's content and never touches real page elements.

Install

<script src="gears.js"></script>

Injects its own <style> tag positioning the canvas behind the element's content, so no companion CSS file is required to render it — but the host element needs its own height/content, since the injected CSS doesn't size it.

Quick Start

<section class="bg-gears" aria-label="Gears background">
  <span class="label">Wind it up</span>
</section>
<script src="gears.js"></script>

No data attribute needed — just apply the class to a container with a size of its own. Auto-initializes against every .bg-gears element. A ResizeObserver keeps the canvas sized to fit: gears stay where they are, since moving one would pull it out of mesh, and new trains fill any space a resize opens up. To configure options: 

Gears.initAll('.bg-gears', {
  toothSize: 3,
  density: 0.2,
  powered: 0.6,
});

Recipes

Pocket watch

Fine teeth, big spoked wheels packed close, nearly every train ticking over slowly, in brass on cream. 

Gears.initAll('.bg-gears', {
  toothSize: 2.5,
  maxTeeth: 54,
  density: 0.45,
  speed: 8,
  powered: 0.8,
  decorate: 'spokes',
  color: '#6b4e16',
  background: '#f7f1e3',
});

Blueprint

Light lines on a dark ground. A dark background also gives the element the bg-gears--dark class, which turns its text white. 

Gears.initAll('.bg-gears', {
  color: '#e8f0ff',
  background: '#1d4e89',
});

Still until touched

No motors at all, and a long coast, so the board sits still until someone spins a gear and then winds down slowly. 

Gears.initAll('.bg-gears', {
  powered: 0,
  coast: 3,
});

Inside a link or carousel

A press on the element may belong to something else, like a card link or a swipeable strip. Turn grabbing off and leave brushing on, so the mouse still pushes gears as it passes. 

Gears.initAll('.card.bg-gears', {
  grab: false,
});

Decorations

decorate sets what's cut out of each gear inside its teeth. The built-in styles are in Gears.decorations:

  • 'auto' — picks by size: 'plain' under 14 teeth, 'holes' from 14 to 21, 'spokes' from 22 up.
  • 'spokes' — five or six spokes between a rim and a hub. Falls back to holes on a gear too small for them.
  • 'holes' — a ring of five or six round holes around the hub.
  • 'plain' — just a hub circle.

Write your own

decorate can also be a function, called once per gear when it's laid out. It's given the gear's Path2D, which already holds the tooth outline, and adds its own subpaths to it. Coordinates are the gear's own: the center is 0, 0 and the shape turns with the gear. The path is only stroked, never filled. The gear object has teeth, radius (the pitch circle), rootRadius (the bottom of the teeth: stay inside it), tipRadius, hubRadius and toothSize. The axle is drawn separately, since it's also the motor marker. 

// A star in every gear big enough for one, and the built-in hub on the rest.
function star(path, gear) {
  if (gear.teeth < 16) {
    Gears.decorations.plain(path, gear);
    return;
  }
  const outer = gear.rootRadius - gear.toothSize * 1.5;
  const inner = outer * 0.45;
  for (let i = 0; i <= 10; i++) {
    const r = i % 2 ? inner : outer;
    const a = (i / 10) * Math.PI * 2;
    const x = r * Math.cos(a);
    const y = r * Math.sin(a);
    if (i === 0) path.moveTo(x, y);
    else path.lineTo(x, y);
  }
}

Gears.initAll('.bg-gears', { decorate: star });

Options

OptionDefaultDescription
toothSize4The gear module, in px. Every gear shares it so they can mesh, and a gear with N teeth has a pitch radius of N × this / 2, so it also scales the gears
maxTeeth36Most teeth a gear can have. The fewest is always 8, and sizes lean toward the small end
density0.3Share of the element the gears' pitch circles cover. Gears keep a gap of two tooth sizes from anything they don't mesh with, so past about 0.45 there's rarely room for more
speed16How fast a motor moves its train's teeth, in px/sec, ±25% per train. Each gear turns at this over its own radius
powered0.5Share of trains with a motor. Each train has a fixed roll against it, so changing it switches motors one train at a time rather than reshuffling them
coast1.5Seconds a flicked train takes to settle about two-thirds of the way back to its motor speed, or to a stop
grabtrueWhether pressing on a gear grabs it. A drag turns it under the cursor and letting go mid-turn flicks it. On touch, a touch on a gear turns it instead of scrolling the page. A click that ends a drag is cancelled, and a tap on a gear that doesn't drag still clicks through, so the element can sit inside a link. Presses on links, buttons and form fields inside the element are left alone
brushtrueWhether moving the mouse across a gear pushes it. It only ever speeds a gear up or turns it the other way, never slows it in the direction it's already going. Mouse only
decorate'auto'A built-in style name or a function. See Decorations
color'#000000'Line color, any CSS color
background'#ffffff'Canvas background, any CSS background. A dark color adds the bg-gears--dark class (white text) to the element. A see-through color is judged as it looks over the host's background. 'transparent' or null leaves the host's own background showing
lineWidth1.25Stroke width in px

Methods

MethodDescription
.update(options)Merges new options in. toothSize and maxTeeth lay out a new board. density takes whole trains away, newest first, or adds new ones around the rest. decorate redraws every gear where it is. Anything else applies on the next frame without moving anything.
.randomize()Lays out a fresh board with the same settings.
.destroy()Stops the animation loop, disconnects the observers, removes the pointer listeners and the canvas.
Gears.get(elOrSelector) / Gears.getAll(selector)Static lookups for already-initialized instances, by element/selector.
Gears.decorationsThe built-in decoration functions, for a custom one to build on.

Notes

Trains are laid out as trees, each gear meshing with exactly one gear before it and kept clear of every other, so no loop of gears can jam. A train is at least two gears. The teeth are simple trapezoids, slimmer than real involute teeth, which is what lets them mesh without their outlines crossing down to 8 teeth. The loop pauses when the element is scrolled well out of view. Respects prefers-reduced-motion by drawing one still frame with no motors running; dragging a gear still turns its train, but it stops when you let go, and brushing does nothing.
