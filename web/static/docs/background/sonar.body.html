Sonar

A canvas background where a click sends out a ping. A hairline ring spreads from the cursor, bounces off whatever is visible inside the element, and leaves a trail of points on each surface it strikes, so outlines build up like a sonar return, letter shapes included. It fades with distance and loses some strength at every bounce. The surfaces come from the page itself, read fresh on every ping, so the ring bounces off the element's real content. It sits behind that content and never changes it.

Install

<script src="sonar.js"></script>

Injects its own <style> tag positioning the canvas behind the element's content, so no companion CSS file is required to render it — but the host element needs its own height/content, since the injected CSS doesn't size it.

Quick Start

<section class="bg-sonar" aria-label="Sonar background">
  <div class="card">Something to bounce off</div>
</section>
<script src="sonar.js"></script>

No data attribute needed. Just apply the class to a container with a size of its own. It initializes itself on every .bg-sonar element. To configure options: 

Sonar.initAll('.bg-sonar', {
  speed: 300,
  range: 900,
  reflectivity: 0.8,
});

What It Hits

The ring only hits things you can see, and it can't pass through them. Starting from the element, each thing inside it is one of these:

  • A visible border is a wall, rounded corners and all. A ring from outside bounces off it and never reaches what's inside. A ping that starts inside bounces around in there. A border on only some sides gives a wall on just those sides.
  • No visible border means the box isn't there as far as the ring is concerned. It passes straight in and hits whatever is inside, by the same rules, and so on down.
  • Solid things are walls the whole way round, and nothing inside them is read. That covers a background that differs from what's behind it, a background image or gradient, a box shadow, and images, SVGs, videos, iframes and form controls.
  • Text is solid. By default, text 24px and up is traced letter by letter: each letter's real outline, holes and all, so a ring bounces off the curve of an "S" and can't get inside an "o". Smaller text is a box per word, since letter outlines that small would just shatter the ring. The text option changes this.

A border counts as visible when it has a width, a style other than none or hidden, and a color that isn't fully transparent. Anything with display: none, zero opacity or visibility: hidden is skipped. Anything clipped by an overflow ancestor is clipped here too. The element's own edges aren't walls: a ring that reaches one just leaves. Turn on showWalls to see exactly what was read.

Recipes

Radar screen

Green on near-black, with a faint glow under the line and points that linger. A dark background also gives the element the bg-sonar--dark class, which turns its text white. 

Sonar.initAll('.bg-sonar', {
  speed: 320,
  range: 1000,
  fade: 2.5,
  glow: 0.12,
  color: '#3dff8b',
  background: '#04140b',
});

Echo chamber

Walls that hardly soak anything up, a long range, and every letter traced, body text included, so one ping rattles around the whole element. 

Sonar.initAll('.bg-sonar', {
  speed: 560,
  range: 2000,
  reflectivity: 0.92,
  fade: 0.8,
  text: 'glyphs',
});

From the element you click

A click on a button, a bordered or filled box, or a large letter sends the ring out of that thing's own outline, so it grows out of the button's shape rather than from the cursor. The click still does whatever it does. A box with only a border sends a ring inward too, to bounce around inside it, and a letter's holes send theirs into the hole. A click on empty space pings from the cursor as usual. 

Sonar.initAll('.bg-sonar', {
  origin: 'element',
});

On its own

Pings from random spots every so often, so the background keeps moving with nobody clicking. 

Sonar.initAll('.bg-sonar', {
  autoPing: 2,
});

From your own code

Send a ping from anywhere, in px from the inside of the element's top-left corner, or out of any element inside it, for instance when something on the page changes. 

const sonar = Sonar.get('.bg-sonar');
sonar.ping(sonar.el.clientWidth / 2, sonar.el.clientHeight / 2);
sonar.emit(document.querySelector('#save-button'));

Options

OptionDefaultDescription
speed380How fast the ring spreads, in px/sec
range800How far a ping travels before it has faded out, in px, distance after a bounce included. It also sets how many rays a ping has, so the front stays smooth all the way out
reflectivity0.7Share of its strength the ring keeps at each bounce. At 1, only distance fades it
fade1.5Seconds the points a ping leaves on what it hits take to fade to about 5%
text'auto'What the ring sees in text. 'glyphs' traces each letter's outline, 'words' puts a box round each word, and 'auto' traces letters 24px and up and boxes smaller words
glow0Strength of a soft glow under the ring's line, from 0 (a clean hairline) to 1
autoPing0Seconds between pings sent out on their own from random spots, or 0 for none
clickToPingtrueWhether a click pings. In 'cursor' mode, clicks on links, buttons and form fields inside the element are left alone, as are clicks inside something solid
origin'cursor'Where a click sends the ring out from: 'cursor', the point clicked, or 'element', the outline of what was clicked. That's the nearest element round the click with a visible border all the way round or a fill, or the letter whose ink was clicked. A click on empty space pings from the cursor either way
showWallsfalseDraws a dashed line along every surface the ring can hit
color'#000000'Ring color, any CSS color
background'#ffffff'Canvas background, any CSS background. A dark color adds the bg-sonar--dark class (white text) to the element. 'transparent' or null leaves the host's own background showing
lineWidth1Width of the ring's line in px. The points it leaves are 1.5 times this across

Methods

MethodDescription
.ping(x, y)Sends a ping out from x, y, in px from the inside of the element's top-left corner. Returns false, and sends nothing, from outside the element or inside something solid.
.emit(el)Sends a ping out of the outline of el, or of the nearest element round it that has one, whatever origin is set to. Returns false, and sends nothing, if there isn't one inside the element.
.update(options)Merges new options in. Everything applies on the next frame, pings in flight included, except text, which applies from the next ping.
.refresh()Reads the walls again and redraws them, for when the content changes while showWalls is on. Pings always read them fresh.
.destroy()Stops the animation loop, disconnects the observers, removes the click listener and the canvases.
Sonar.get(elOrSelector) / Sonar.getAll(selector)Static lookups for already-initialized instances, by element/selector.

Notes

A ping starts as a ring of up to 1,600 rays, enough to keep them about 3px apart at the end of its range. Each ray reflects off the first wall in its way, angle in equal to angle out. The front is drawn by joining neighboring rays that have bounced off the same surfaces, so it folds where it bounces and tears apart at corners. Where a curved surface spreads two neighbors apart, a new ray is traced between them from the start, so the reflected front stays a smooth curve rather than a few straight chords. A ping can grow to 6,000 rays this way. Walls are filed in a coarse grid, so a ray only tests the few near it.

A ping from an element's outline works the same way, with its rays laid out along the outline rather than round a point. Each starts straight out from its stretch of outline, and a fan of rays at each outward corner rounds the front off there.

Letters are drawn into an offscreen canvas in the page's own font, placed where the browser laid each one out, and traced back out of the pixels. Each traced letter is kept per font and character, so retracing a page is quick, and the cache is dropped when a web font finishes loading. The traced outlines are polygons, but along a smooth stretch the surface direction is blended from one corner to the next, so a curve reflects like a curve and not a row of flat mirrors.

The canvas sits behind the content, so a ring inside a filled box would be hidden. That's why clicks inside something solid don't ping, including clicks on a letter's ink. A click inside a letter's hole does ping. Transformed elements are read as their bounding boxes, so a rotated box bounces like the upright box around it. The loop only runs while something is moving or fading, and pauses when the element is scrolled well out of view. Respects prefers-reduced-motion: a click works out the whole ping at once and draws only the points it leaves, which stay until the next one.
