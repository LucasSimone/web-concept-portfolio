Fireflies

A canvas of soft glowing points that wander an open field on their own slowly-turning paths, each blinking independently on a random cycle — a long dark stretch, then a brief rise and fall in brightness (occasionally a quick double-flash instead), then dark again, with a slight twinkle in size as it brightens. Each firefly also carries its own small variation on the base glowColor, which defaults to a warm yellow-green close to real firefly bioluminescence — set it to '0, 0, 0' for a flat monochrome swarm instead. Nothing responds to the cursor; it just keeps drifting. Purely decorative — it sits behind the element's content and never touches real page elements.

Install

<script src="fireflies.js"></script>

Injects its own <style> tag positioning the canvas behind the element's content, so no companion CSS file is required to render it — but the host element needs its own height/content, since the injected CSS doesn't size it.

Quick Start

<section class="bg-fireflies" aria-label="Fireflies background">
  <span class="label">Just watch</span>
</section>
<script src="fireflies.js"></script>

No text/data attribute needed — just apply the class to a container with a size of its own. A ResizeObserver on the host element keeps the canvas sized to fit, clamping any fireflies that would otherwise fall outside the new bounds rather than resetting the whole population. Auto-initializes against every .bg-fireflies element. To configure options: 

Fireflies.initAll('.bg-fireflies', {
  count: 80,
  glowSize: 14,
});

Recipes

Dense, restless swarm

More fireflies moving faster with a shorter dark gap between blinks reads as a busier, more agitated field instead of a calm one. 

Fireflies.initAll('.bg-fireflies', {
  count: 100,
  speed: 30,
  blinkMin: 0.4,
  blinkMax: 1.5,
});

Sparse and lazy

Fewer fireflies, slower drift, and long dark gaps between blinks for a still, sparse night-field feel. 

Fireflies.initAll('.bg-fireflies', {
  count: 18,
  speed: 6,
  wander: 0.4,
  blinkMin: 3,
  blinkMax: 8,
});

Bigger, softer glow

glowSize controls the halo radius at peak brightness — larger values read as bigger, softer light sources rather than pinpricks. 

Fireflies.initAll('.bg-fireflies', { glowSize: 20 });

Flat monochrome

A fully desaturated glowColor like black or white skips the per-firefly hue variation, so every firefly renders in exactly the same shade instead of a swarm of near-neighbors. 

Fireflies.initAll('.bg-fireflies', {
  glowColor: '0, 0, 0',
});

Dark sky, light fireflies

background and glowColor are independent, so inverting to a dark field with pale fireflies is just an option change away. 

Fireflies.initAll('.bg-fireflies', {
  background: '#050505',
  glowColor: '255, 255, 255',
});

Options

OptionDefaultDescription
count100How many fireflies are alive at once
speed25Base drift speed in px/sec; each firefly varies it by ±40%
wander1.4How sharply each firefly's heading randomly turns per second. Higher looks more erratic
blinkMin1.2Minimum dark gap between blinks, in seconds
blinkMax4Maximum dark gap between blinks, in seconds
visibleMin0.4Minimum time a firefly stays lit during a blink, in seconds
visibleMax1.1Maximum time a firefly stays lit during a blink, in seconds; stretched further on a double-flash
glowSize9Halo radius at peak brightness, in px; each firefly varies it by ±30%
background'#ffffff'Canvas fill color drawn behind the fireflies each frame
glowColor'154, 205, 50'RGB triplet (no rgb() wrapper) for the glow/core color; each firefly jitters its own hue/lightness slightly around it. Use a desaturated value like '0, 0, 0' for flat monochrome

Methods

MethodDescription
.update(options)Merges new options in. Changing count adds or removes fireflies immediately; any other option just applies on the next frame.
.destroy()Stops the animation loop, disconnects the resize observer, and removes the canvas.
Fireflies.get(elOrSelector) / Fireflies.getAll(selector)Static lookups for already-initialized instances, by element/selector.

Notes

Double-flash odds are fixed (not configurable) — blinkMin/ blinkMax control the dark pacing between blinks, and visibleMin/visibleMax control how long each blink stays lit, which together are what actually shape how the field feels — so the field never falls into visible lockstep even with a small population. Drifting fireflies wrap around the edges of the host element instead of bouncing off them. Respects prefers-reduced-motion by skipping the animation loop entirely and rendering every firefly at a fixed mid-blink brightness, so the field is still visible but static. The demo page's own control panel adds a Profile dropdown with a few preset combinations (dense/restless, sparse/lazy, quick flicker, slow glow, monochrome) as a starting point — picking one just sets the sliders below it, which stay freely editable afterward. It also exposes a raw color picker for glowColor — reach for glowColor/ background directly in code for anything more specific.
