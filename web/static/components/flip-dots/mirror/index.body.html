Mirror

The same component as the demo next door, playing your camera. Each frame the board asks a function for content, the function hands back the camera’s current picture as a grid of states, and a few thousand discs turn to meet it. Nothing in the component knows what a camera is: it plays a sequence, and this sequence happens to be live.

The video never leaves this page. Nothing is uploaded, recorded or sent anywhere: each frame is drawn to a canvas, averaged down to the size of the grid, and thrown away. Stopping the camera releases it.

How it is wired

Six lines, and none of them are about cameras

play() takes either an array of frames or a function to ask for one. imageGrid() turns anything drawable — a <video>, an <img>, a canvas — into the same (x, y) => state accessor a hand-written pattern uses. Putting one inside the other is this entire page. 

const board = FlipDots.get('#board');

board.play(() => FlipDots.imageGrid(video, board.cols, board.rows, {
  levels: board.options.palette.length,
  mirror: true,
  autoLevels: true,
  dither: 'ordered',
}), { fps: 20 });

The grid is measured off the element’s own box, so the camera is resampled to fit the board rather than the reverse. Change the dot size above and the next frame arrives at the new resolution with nothing to rewire.

Why ordered dither, by default, on a board

A two-color board has no grays, so every shade in between has to become a pattern of dots dense enough to pass for it. Diffusion dithering wins that job by every measure print cares about. But here each changed dot is a disc that physically turns, and diffusion carries every cell’s error into its neighbors — so one pixel moving in the corner of the frame changes the answer everywhere after it, and a perfectly still scene still costs hundreds of flips a second. Ordered dither thresholds each cell against a fixed position instead. A still scene gives an identical frame, and an identical frame flips nothing. Switch between the two above and listen to the difference.

Live color — a palette lifted from the room

Every other palette here was decided in advance. Set it to Live color and the board works in the colors of your room instead. FlipDots.imagePalette() clusters the frame down to the six colors actually in it; those become the palette, and imageGrid’s match option sends each cell to the nearest one instead of to a step on a brightness ramp. A disc is no longer light or dark — it is the color of whatever is in front of you. 

const palette = FlipDots.imagePalette(video, 6, { seed: board.options.palette });
board.update({ palette });

FlipDots.imageGrid(video, board.cols, board.rows, { match: palette });

The palette is re-clustered about once a second, not every frame, seeded with the previous answer, and only adopted once a color has actually moved. All three guard the same thing the dither note does: a palette index is a dot’s state, so reordering the palette reassigns every disc at once. Two clusters of near-equal brightness will swap places on sensor noise alone — a board that flickers every second while the room sits perfectly still. Seeding keeps cluster six meaning cluster six. The deadband keeps a still room producing the identical palette, and an identical palette flips nothing.

The frame rate of a disc

The board plays at 20fps and each disc takes 110ms to turn, so frames land while the last turn is still in the air. That is on purpose: a dot handed a new state mid-flight keeps its momentum and re-aims instead of restarting, so fast motion smears across the panel the way it does on a real one. Past that point more frames buy no more picture — they just mean a larger share of the board never finishes a turn.
