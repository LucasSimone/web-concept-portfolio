Gravity Well

A canvas-based wireframe grid that acts like a sheet with the cursor pulling on it: every grid vertex is displaced toward the pointer, falling off smoothly with distance so nearby points bend hardest and distant ones barely move. The pull point eases toward the real cursor and its strength eases in/out on enter/leave, so the grid settles rather than snapping. Purely decorative — it sits behind the element's content and never touches real page elements.

View Demo Download JS

Install

<script src="gravity-well.js"></script>

Injects its own <style> tag positioning the canvas behind the element's content, so no companion CSS file is required to render it — but the host element needs its own height/content, since the injected CSS doesn't size it.

Usage

<section class="bg-gravity-well" aria-label="Gravity well background">
  <span class="label">Move your cursor over this section</span>
</section>
<script src="gravity-well.js"></script>

No text/data attribute needed — just apply the class to a container with a size of its own. A ResizeObserver on the host element rebuilds the grid/canvas to fit. Auto-initializes against every .bg-gravity-well element. To configure options: 

GravityWell.initAll('.bg-gravity-well', {
  radius: 160,
  strength: 60,
});

Options

OptionDefaultDescription
cell16Grid spacing in px between vertices
radius90How far from the pull point the effect reaches, in px
strength45Maximum distance a grid vertex gets pulled, in px
ease0.18Per-frame lerp factor for both the pull point and its strength; lower feels heavier/laggier
mode'grid''grid' draws the mesh lines; 'dots' draws only the vertices
dotRadius1.6Dot radius in px, used only when mode is 'dots'
background'#ffffff'Canvas fill color drawn behind the grid each frame
lineColor'0, 0, 0'RGB triplet (no rgb() wrapper) for grid line/dot color
lineOpacity0.3Opacity of grid lines/dots

Notes

Displacement is capped per-vertex at 85% of that vertex's distance to the pull point, so a vertex can never overshoot past the cursor and fold the mesh over itself. Respects prefers-reduced-motion by skipping the animation loop entirely — the grid still responds to pointer position, but each state renders as a single immediate frame with no easing.
