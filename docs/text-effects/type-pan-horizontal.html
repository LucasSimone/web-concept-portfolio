Type Pan Horizontal

The horizontal twin of Type Pan Vertical — captures mouse-wheel input directly on the element instead of page scroll and converts it into typing progress. The caret always sits right after the last revealed character, and the line pans left once it outgrows the element. Reverse-wheel rewinds.

View Demo Download JS

Install

<script src="type-pan-horizontal.js"></script>

Self-contained — it injects its own <style> tag (layout height, viewport clipping, blink keyframes) on first use, so no companion CSS file is required.

Usage

<div class="type-pan" data-text="Scroll to reveal the whole headline">
  Scroll to reveal the whole headline
</div>
<script src="type-pan-horizontal.js"></script>

Reads data-text or trimmed textContent. Auto-initializes against every .type-pan element. To switch drive mode and configure options: 

TypePanHorizontal.initAll('.type-pan', {
  sensitivity: 1,
  panPosition: 0.75,
  driveMode: 'continuous',
});

Options

OptionDefaultDescription
driveMode'scroll''scroll' (wheel-driven) or 'continuous' (self-animating type/hold/erase clock)
panPosition0.65Fraction of element width the caret pins to once text overflows
lag0.18Smoothing (0–1) applied to pan movement; higher is snappier
eraseOnReversetrueErase typed characters on reverse wheel input (scroll mode only)
cursorBlinktrueWhether the caret blinks
sensitivity1Multiplier applied to wheel delta before it becomes typing progress
typeDuration2200ms to type the full line (continuous mode)
holdDuration1000ms held fully typed before erasing (continuous mode)
rollbackSpeed700ms to erase back to empty (continuous mode)

Notes

In scroll mode the element captures wheel events with { passive: false } and calls preventDefault(), so the page won't scroll while the pointer is over it. Call .reset() on an instance to reset typing progress to the start.
