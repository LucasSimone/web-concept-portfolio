Text Effect · Scroll-driven

In Flight Out

Splits text into per-character spans that fly in from scattered off-screen paths, assemble and hold while the element crosses the viewport, then fly apart and off-screen again — driven exactly by scroll position, so it's fully reversible.

View Demo Download JS

Install

<script src="in-flight-out.js"></script>

Self-contained — it injects its own <style> tag on first use, so no companion CSS file is required.

Usage

<div class="in-flight-out" data-text="In Flight Out">In Flight Out</div>
<script src="in-flight-out.js"></script>

Reads data-text or trimmed textContent. Auto-initializes against every .in-flight-out element. To configure options: 

InFlightOut.initAll('.in-flight-out', {
  scatter: 0.45,
  maxDistance: 60,
  rotation: 0.4,
  maxAngle: 40,
});

Options

OptionDefaultDescription
scatter1Multiplier scaling how far entry/exit points are from center
maxDistance140Cap on flight distance, as % of viewport diagonal
rotation0.40–1 chance-and-intensity dial for how many/how much letters rotate
maxAngle60Max rotation angle in degrees when rotation is fully active
entryPercent48Share of scroll progress spent on the entry animation
hangPercent10Share of scroll progress the text holds fully assembled
exitPercent42Share of scroll progress spent on the exit animation
path'linear''linear' (enter below / exit above, like credits) or 'random' (each letter enters/exits from a random viewport edge)

Notes

Call .reshuffle() on an instance to re-roll random entry/exit points and rotation without rebuilding the DOM or touching options. Scroll-driven only — no continuous mode.
